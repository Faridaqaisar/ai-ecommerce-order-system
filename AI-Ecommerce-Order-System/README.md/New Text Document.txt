# 🛍️ AI Ecommerce Ordering System

## 📌 Project Overview
This project is a complete ecommerce ordering system built using Lovable (frontend) and n8n (backend automation).  
Users can browse products, add to cart, place orders, and receive email confirmations.

---

## 🚀 Features
- Product listing (Shoes, Clothing, Accessories)
- Category filtering (Men, Women, Kids)
- Add to cart system
- Order creation
- Email confirmation (Gmail integration)
- User authentication (Register / Login / Email Verification)

---

## 🧠 Tech Stack
- Frontend: Lovable AI
- Backend: n8n workflows
- Database: Google Sheets
